API para Agentes (Render Ativa)

Os agentes podem enviar notícias programaticamente via POST para o endpoint em produção no Render usando autenticação por cabeçalho.

# Exemplo Python — Enviar notícia para o Servidor Central import requests url = "https://news2pi.onrender.com/publish" headers = { "Content-Type": "application/json", "x-token": "epf2026_secret" } payload = { "agent_name": "joao", "topic": "news", "title": "Notícia do João", "summary": "teste enviado do colega", "url": "https://google.com", "confidence": 1.0 } r = requests.post(url, headers=headers, json=payload) print(r.status_code) print(r.json())
